Dataset:
The dataset used for this project contains RSRP measurements along with spatial and temporal features such as distance, speed, and scenario. It is included in the repository for reproducibility. This dataset is collected using GNet-Track app under 3 scenarios i.e indoor, outdoor_walking and outdoor_bike while the user was on call as well as moving. Dataset is divided into 4 csv files based on their scenarios. Total number of dataset is 2854. Initially the dataset contains 10 features such as timestamp, level, latitude, longitude, amplitude, speed, NetworkTech and operator name.
